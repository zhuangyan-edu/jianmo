# jianmo：AI 视频「拔刀」镜头的可交互 3D 复刻

这份文档是项目的交接说明：目标是什么、已经定了哪些路线、素材现状、下一步做什么。
新开的对话（包括换账号后的对话）先读完这一份再动手。

## 1. 目标

把一段 4.9 秒的 AI 生成视频复刻成浏览器里的实时 3D 场景：

- **原片内容**：短发、白衬衫、深色裙的少女在废墟平台上半蹲拔刀，刀口爆出蓝白色电光和水花；背景是废墟和斜射的暖色逆光，前景有大颗虚化光斑，景深很浅。
- **必须做到**：能自由拖动视角观看，不是只能从原片机位看。
- **要加的原创内容**：拔刀之后来一段很帅的爆发（见第 5 节）。
- **验收标准**：氛围和镜头接近原片即可，**不要求逐像素一致**。
- **不做**：原片上的 "XIAOWANG Production" 水印不复刻。

原片视频没有放进仓库（仓库是公开的）。新对话需要对照原片时，请用户重新上传那段录屏。

## 2. 已定的路线

| 决定 | 结论 | 原因 |
|---|---|---|
| 技术栈 | 单页 HTML + Three.js，实时渲染 | 要能自由转视角 |
| 主角来源 | **用户用 Tripo 生成的模型**，不再走纯代码建模 | 纯代码做的脸到不了原片的精细度；用户只看最终画面 |
| 贴图 | 用去光版 | 视角和灯光都会变，电光要实时打在角色身上 |
| 骨骼 | 用自动绑定的 Mixamo 骨架（带手指） | 蹲姿和握刀需要可靠的蒙皮权重 |
| 头发、裙摆 | 不绑骨骼，用物理或顶点 shader 让它们飘 | 原片里两者都在动 |
| 特效、光斑、烟尘、体积光 | 全部用代码做 | 都是动态或虚化的东西，代码更可控 |
| 远景 | 2:1 全景天空图做环境光和背景（用户生成，**还没上传**） | 提供环境光和反光 |
| 模型分工 | 画面相关的全部由主线程做；接口明确的模块（闪电、粒子、布料）可交给子代理；另用一个全新上下文的代理只看原片帧和截图来挑差距 | 风格统一最重要，拆太散会不协调 |

早期做过一个纯代码生成的动漫头模（`face/index.html`，约 20 万面，浏览器里现场生成）。
它证明了逆光、皮肤透光、眼睛发光这套 shader 可行，但脸和头发不够好，**现在只作为 shader 参考，主角不用它**。

## 5. 实施路径

目前只完成了素材检查，下面的步骤都还没开始。

1. **减面和压缩**。把高面数模型减到网页能加载的规模，贴图压到 2K，输出到开发分支（例如 `assets/`）。
   目标：头 3–5 万面，刀 1 万，废墟 10 万左右。原始文件留在 `upload-3d-models` 分支不动。
2. **换头**。把绑骨全身模型里属于头和头发的顶点切掉，把新头摆正、对齐到脖子，刚性挂在 `mixamorig:Head` 骨骼上，接缝处匹配肤色。
   - 首选 `anime girl head`（整体最像原片）。头发和头一体，飘动用顶点 shader 按"离头皮的距离"摆动发梢。
   - 如果发梢摆动效果不够，换成 `bald female head` + `hair wig`，头发是独立网格，更好做动态。
3. **角色转台**。纯色背景下只放角色，套上最终的光照和 shader（逆光勾边、皮肤透光、眼睛发光），从正面、侧面、原片机位截图确认。**这一步过关再往下做。**
4. **姿势和动画**。半蹲拔刀的关键帧动画；刀拆成刀身和刀鞘，分别挂到手和腰上。
5. **场景和后期**。废墟平台、天空、雾和体积光；HDR 管线加景深光斑、辉光、运动模糊、调色、胶片颗粒。
6. **特效和爆发**。程序化闪电、水花、粒子。爆发段：出鞘瞬间短暂慢动作、地面冲击波、电弧四散、碎石浮空、镜头震动、一道刀光劈开远处烟尘。
7. **镜头和交互**。时间轴默认复刻原片运镜，可一键切到自由环绕，带时间条和慢放。
8. **对照迭代**。每改一轮用无头浏览器截图，和原片抽帧并排比较。

## 6. 已知风险

- **脸的近景**。原片靠刘海遮眼、逆光和浅景深藏住了脸，复刻时这些手段照用；贴脸正面特写仍是最弱的地方。
- **换头接缝**。两个模型的肤色和脖子粗细不一致，衣领能遮住一部分，剩下的要调色。
- **绑骨模型的蒙皮质量没验证过**。只看过 T 字姿势，蹲姿下肩、胯、裙子的变形要到第 4 步才知道。
- **体积**。原始素材约 480 MB，减面后预计几十 MB，早期"1.4 MB 纯代码"的设想已经放弃。
- **许可**。仓库是公开的，模型文件等于公开分发。Tripo 生成物的使用条款由用户自己确认。

## 7. 工具

脚本在 `tools/`，需要 Node 和 Playwright（云端环境已预装 Chromium 和 Playwright）。

```bash
cd tools && npm install          # 只装 three

# 取出某个模型（原始模型不在开发分支上）
git fetch origin upload-3d-models
git show "origin/upload-3d-models:anime girl head 3d model.glb" > /tmp/head.glb

node info.js /tmp/head.glb       # 面数、骨骼、贴图、包围盒
node view.js /tmp/head.glb out.png          # 四视图：正、侧、背、斜俯
node view.js /tmp/body.glb out.png 0.8 1.0  # 只看高度 80%–100% 的部分（头部特写）
node shot.js out.png             # 给 face/index.html 截图
```

没有 GPU 的环境用 SwiftShader 软件渲染，200 万面的模型也能出图，只是慢一些。
